# Пословица к месту / Russian Proverbs

[English](README.md) | **Русский**

Скилл для AI-агентов: подобрать русскую пословицу или поговорку под смысл, ситуацию и тон текста, объяснить её и проверить уместность.

Инструкции скилла и справочные материалы написаны по-русски. Скилл предназначен для русской речи, включая разговорные формы; английский README помогает познакомиться с ним международной аудитории.

В базе — 228 выражений и 13 вариантов из сборника М. А. Рыбниковой «Русские пословицы и поговорки» (1961). У записей есть страницы источника, краткий смысл, ситуации употребления, тон и ограничения. Скилл помогает выбрать выражение или оставить текст без него, если подходящего варианта нет.

## Установка

Для поиска нужен Python 3.9 или новее. Дополнительные пакеты и API не требуются.

### Через skills.sh

При установленном Node.js выполните:

```bash
npx skills add ai-some-skills/russian-proverbs
```

CLI предложит выбрать агента и область установки. Подробнее — в [документации skills.sh](https://skills.sh/docs). Каталог [skills.sh](https://skills.sh) учитывает установки через CLI; сама публикация на GitHub не гарантирует немедленного появления в каталоге.

### Напрямую из GitHub

Попросите Codex:

```text
Установи скилл из https://github.com/ai-some-skills/russian-proverbs
```

Для ручной установки в личный каталог скиллов Codex:

```bash
git clone https://github.com/ai-some-skills/russian-proverbs.git \
  ~/.agents/skills/russian-proverbs
```

Если папка уже существует, сначала проверьте её содержимое. Для Claude Code используйте `~/.claude/skills/russian-proverbs` вместо пути выше. `SKILL.md` должен находиться в корне папки скилла.

## Использование

Примеры запросов:

- «Подбери поговорку: команда долго готовится, пора попробовать простое обратимое решение».
- «Добавь одну уместную пословицу в этот текст, без назидания».
- «Объясни смысл поговорки и проверь, не прозвучит ли она как упрёк».
- «Используй $russian-proverbs: поддержи человека после первой ошибки».

Обычная просьба написать текст по-русски сама по себе не включает пословицы в каждый ответ.

## Как устроен поиск

Агент читает короткую инструкцию и запускает локальный поиск. База остаётся на диске; по умолчанию в ответ скрипта входят до пяти кандидатов и до 5000 символов суммарно. Сетевых запросов, API и телеметрии нет.

Из корня репозитория можно проверить поиск вручную:

```bash
python3 scripts/search.py 'сначала проверить решение которое трудно отменить' --limit 3
python3 scripts/search.py 'поддержать после первой ошибки' --tone supportive
python3 scripts/search.py --id ryb-0045 --details
```

Для первого запроса в проверенной версии первым находится «Семь раз примерь, а один отрежь» — именно такая формулировка приведена в выбранной записи книги. Скрипт возвращает JSON. Параметр `--details` добавляет исходную форму, варианты и сведения о проверке.

Поиск лексический, с простой обработкой словоформ. Иногда запрос приходится переформулировать. Порядок выдачи не гарантирует уместность: окончательный выбор делает агент по контексту и ограничениям записи.

## Источник и ограничения корпуса

М. А. Рыбникова. **Русские пословицы и поговорки**. Ответственный редактор Б. П. Кирдан. Москва: Издательство Академии наук СССР, 1961. Использован предоставленный пользователем PDF из 230 страниц; контрольная сумма записана в [манифесте источников](data/sources.json).

Сборник отражает преимущественно записи 1930-х годов. Наличие выражения в книге не доказывает его современную распространённость. Смысл, ситуации, тон и ограничения — редакторская разметка этого проекта, а не цитаты из толкований составительницы. Поле `source_note`, если присутствует, содержит отдельно обозначенное пояснение книги.

Все включённые формулировки и варианты сопоставлены с текстовым слоем PDF; четыре записи дополнительно сверены со сканом. Полная визуальная вычитка не выполнена. Исходный PDF, полный текст книги и приложение литературных афоризмов в репозиторий не включены.

Правила сопровождения базы и значения полей описаны в [справке по корпусу](references/corpus.md).

## Проверки

Из корня репозитория:

```bash
python3 scripts/validate.py
python3 -m unittest discover -s evals -p 'test_*.py' -v
```

При подготовке первой версии прошли проверка структуры корпуса и девять автоматических тестов: подбор по ситуациям, поиск вариантов, фильтры, отсутствие совпадений, различение противоположных пословиц, лимиты выдачи и запуск из другой директории. В [сценариях для агента](evals/evals.json) проверяются также поддержка после ошибки, точность технического требования и переход от подготовки к пробе. Эти пробы не доказывают качество на любых запросах.

Необязательная повторная сверка с исходным PDF требует пакета `pypdf`:

```bash
python3 scripts/validate.py --pdf /путь/к/книге.pdf
```
